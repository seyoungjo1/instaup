개인정보처리방침

시행일: 2026년 11월 2일

1. 대상

y3dsy 업로더(이하 "도구")는 운영자 한 명이 본인의 YouTube 채널과 Instagram 계정에 영상을 올리기 위해 만든 개인용 도구입니다. 일반 사용자에게 제공되지 않습니다.

2. 사용하는 정보

  • Google(YouTube): 운영자가 승인한 범위(youtube.upload, youtube.readonly) 안에서 채널 이름을 확인하고 영상을 업로드합니다.
  • Instagram: 운영자 계정의 ID·사용자 이름을 확인하고 릴스를 게시합니다.
  • 업로드하는 영상·이미지·설명 글은 운영자가 직접 만든 것입니다.

3. 보관

로그인 후 발급되는 접근 토큰은 운영자 PC에만 저장되며, 이 사이트나 다른 서버로 전송하지 않습니다. 게시용 영상은 Instagram이 내려받을 수 있도록 게시 직전에만 공개 저장소에 잠시 올리고, 게시가 끝나면 지웁니다.

4. 제3자 제공

업로드 대상인 Google(YouTube)과 Meta(Instagram) 외에는 어떤 정보도 제공·판매·공유하지 않습니다. 광고나 분석 도구를 쓰지 않습니다.

5. Google API 데이터 사용

이 도구가 Google API로 받은 정보의 사용과 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다. YouTube 사용은 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

6. 권한 철회

Google 권한은 Google 계정 권한 페이지에서, Instagram 권한은 Instagram 앱의 설정 → 앱 및 웹사이트에서 언제든 철회할 수 있습니다. 철회하면 저장된 토큰은 더 이상 쓸 수 없습니다.
